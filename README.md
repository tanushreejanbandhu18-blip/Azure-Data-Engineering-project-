🚀 End-to-End Azure Data Engineering Pipeline using Azure Data Factory, Databricks, Synapse Analytics & Power BI
Implementing Medallion Architecture (Bronze → Silver → Gold) for Adventure Works Data Analytics  


This project demonstrates the implementation of a complete Azure Data Engineering solution using Azure Data Factory, Azure Data Lake Storage Gen2, Azure Databricks, Azure Synapse Analytics, and Power BI.

The project follows the Medallion Architecture approach, where data is processed through Bronze, Silver, and Gold layers to ensure data quality, scalability, and analytical readiness.

Raw Adventure Works datasets were ingested from HTTPS sources using Azure Data Factory pipelines, transformed using Azure Databricks, curated in Azure Synapse Analytics, and finally visualized through an interactive Power BI dashboard.

📥 Azure Data Factory – Data Ingestion Layer

Azure Data Factory was used to orchestrate and automate the data ingestion process.

The source Adventure Works datasets were accessed through HTTPS endpoints and ingested into Azure Data Lake Storage Gen2 using metadata-driven pipelines. The pipelines were designed to automate data movement and reduce manual intervention.

Key Activities
Created Linked Services
Configured HTTPS datasets
Built ingestion pipelines
Automated data movement
Pipeline monitoring and execution

🗄️ Azure Data Lake Storage Gen2 – Bronze Layer

The Bronze Layer serves as the landing zone for raw data.

Data ingested through Azure Data Factory pipelines is stored in its original format without any transformations. This layer preserves source data integrity and acts as a foundation for downstream processing.

Bronze Layer Objectives
Store raw source files
Preserve original datasets
Enable data traceability
Support future reprocessing

⚡ Azure Databricks – Data Transformation Layer

Azure Databricks was used to perform data engineering and transformation activities on the raw datasets stored in the Bronze Layer.

PySpark notebooks were developed to cleanse, validate, and standardize the data before loading it into the Silver Layer.

Transformations Performed
Data cleansing
Null value handling
Data type conversion
Schema validation
Business rule implementation
Data quality checks

🗄️ Azure Data Lake Storage Gen2 – Silver Layer

The Silver Layer contains cleansed and transformed datasets generated by Azure Databricks.

This layer stores trusted and standardized data that is ready for analytical processing and reporting.

Silver Layer Benefits
Improved data quality
Consistent schema structure
Analytics-ready datasets
Enhanced reliability

🏢 Azure Synapse Analytics – Gold Layer

Azure Synapse Analytics was used to build the final analytical layer of the solution.

External tables and SQL views were created on top of the Silver Layer datasets to provide business-ready data models for reporting and analysis.

The Gold Layer contains curated datasets such as ExtSales and supporting dimension views.

🔄 End-to-End Pipeline Workflow
Data extracted from HTTPS source systems.
Azure Data Factory pipelines ingest data into the Bronze Layer.
Azure Databricks transforms and cleanses raw datasets.
Processed data is stored in the Silver Layer.
Azure Synapse Analytics creates Gold Layer views and reporting datasets.
Power BI consumes Gold Layer data for business reporting and visualization.
🎯 Project Outcome

This project successfully demonstrates the implementation of a scalable cloud-based data engineering platform using Microsoft Azure services.

By integrating Azure Data Factory, Azure Data Lake Storage Gen2, Azure Databricks, Azure Synapse Analytics, and Power BI, an automated end-to-end data pipeline was developed to transform raw data into actionable business insights.

The solution follows Medallion Architecture principles and showcases industry-standard practices for data ingestion, transformation, warehousing, and analytics within a modern cloud ecosystem.
